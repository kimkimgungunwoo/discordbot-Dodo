# 증강 선택 기본 규칙

## 범위

사용자 지정: 3장 중 1장 선택, 각 카드 위치별 1회 개별 리롤, 실버/골드/프리즘 3등급, 개인별 출발선 통과 기준 최대 4개 획득.

이 문서는 현재 마블의 선택 규칙이다. 실제60개 카드와 효과는 [augment-marble-abilities.md](augment-marble-abilities.md)를 따른다.

## 획득

| 획득 회차 | 조건 |
|---|---|
| 1 | 경기 시작 전 |
| 2 | 개인 출발선 1회 통과 |
| 3 | 개인 출발선 3회 통과 |
| 4 | 개인 출발선 5회 통과 |

최초에는 좌석 순서대로 증강을 선택하고 모두의 첫 선택이 완료된 뒤 첫 주사위를 굴린다. 이후에는 조건을 달성한 당사자만 선택한다. 시작 시점의 위치는 통과로 세지 않는다. 정상 이동으로 출발 칸에 정확히 도착하는 것도 1회 통과로 센다. 3연속 더블로 휴식 칸에 강제 이동하는 것은 통과가 아니다.

출발 통과 처리 순서: 이동 위치·통과 횟수 갱신 → 월급100 지급 → 보유 토지가의5% 세금 정산(필요 시 매각·파산) → 생존 시 증강 선택 → 도착 칸 처리. 새 증강은 선택 이후부터 적용할 수 있도록 한다. 이미 받은 이번 월급과 이번 토지세를 소급해서 다시 계산하지 않는다. 더블에 의한 추가 행동과 원래 차례는 선택 후에도 유지된다.

## 등급

매 경기 서버가 획득 회차 4개의 등급을 한 번씩 추첨한다. 같은 회차는 모든 참가자에게 같은 등급을 제공한다. 획득 시점이 달라도 2번째 획득 등급은 모두 같다. 미래 회차의 등급은 공개하지 않는다.

초기 설정값은 회차마다 실버 40% / 골드 40% / 프리즘 20%. 등급 확률은 별도 상수로 변경 가능하며 이 비율은 사용자 확정값이 아닌 임시 기본값이다. 특정 회차의 상위 등급 보장이나 리롤 시 등급 상승은 없다.

## 카드 선택·리롤

- 동일 등급의 서로 다른 카드3장을 제시한다(전환으로 후보가 소진된 경우 남은 수만큼).
- 그중 1장을 선택하면 즉시 획득하며 나머지 2장은 버린다.
- 왼쪽·가운데·오른쪽 각각 독립된 리롤 1회를 갖는다. 한 선택 화면에서 총 최대 3회다.
- 리롤은 해당 위치만 같은 등급의 다른 카드로 바꾼다. 교체된 카드도 그 위치에서 다시 리롤할 수 없다.
- 매 획득 회차마다 3개 위치의 리롤 횟수가 초기화된다. 남은 리롤은 이월하지 않는다.
- 이미 보유한 증강과 현재 선택 화면에서 한 번이라도 본 증강은 후보에서 제외한다.
- 미선택 카드는 다음 획득 회차에 다시 나올 수 있다. 다른 플레이어끼리는 같은 증강을 가질 수 있다.
- 획득한 증강은 계속 보유하며 교체·삭제하지 않는다. 동일 증강 중복 획득은 없다.

## 제한 시간·공개 범위

선택 시간은 30초다. 리롤·잘못된 요청·재접속으로 시간이 초기화되지 않는다. 시간 초과 시 현재 표시된 왼쪽 카드를 자동 선택한다. 봇도 같은 선택 과정을 따른다.

선택하는 동안 보드 진행은 멈춘다. 초기 증강 선택에서도 모두 선택을 마치기 전에는 이동하지 않는다. 선택지와 리롤 사용 상태는 당사자에게만 보내고 상대·관전자에게는 공개하지 않는다. 획득한 증강은 전원에게 공개한다. 서버는 매 요청의 참가자·현재 선택 회차·경기 ID·턴 ID·상태 버전을 검증한다.

## 코드 구조와 현재 상태

- `games/shared/augment-marble-augments.ts`: 등급·획득 조건·추첨·3장 제시·개별 리롤·선택·공개 범위.
- `games/shared/augment-marble.ts`: 통과 횟수, 초기 선택 단계, 도착 처리 중단·재개, 자동 선택.
- `games/server/src/augment-marble-room.ts`: 권한, 비공개 정보, 서버 난수, 선택 제한 시간과 재접속.
- `games/client/src/augment-marble/main.ts`: 카드 3장, 개별 리롤, 보유 증강 표시.

실제 카탈로그60종이 등록되어 일반 게임에서 선택과 효과가 활성화된다. 획득 회차는 보유 개수와 분리한다. 전환 때문에 보유 개수가 늘어도 정규4회 획득을 유지한다. 전환으로 후보가 줄면 남은 카드 수만큼 제시하고 더 이상 교체 후보가 없을 때 리롤을 비활성화한다.

카탈로그는 중복ID, 잘못된 등급·훅, 후보 부족을 시작 전에 검증한다. 일반 카탈로그는 등급별20종이다. 테스트용 카드는 테스트 파일에서만 정의한다.
