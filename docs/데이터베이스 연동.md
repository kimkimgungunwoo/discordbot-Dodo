# 데이터베이스 연동

## 개요
FastAPI + SQLAlchemy 2.0 (async) + PostgreSQL 조합으로 봇에 DB를 연결했다.
Alembic으로 마이그레이션을 관리한다.

## 기술 스택
- **SQLAlchemy 2.0** — async ORM (`AsyncSession`, `mapped_column`)
- **asyncpg** — async PostgreSQL 드라이버
- **Alembic** — 마이그레이션 도구
- **greenlet** — SQLAlchemy async 내부 의존성

## 디렉토리 구조

```
api/
├── database.py       # 엔진, 세션, Base 정의
├── models/           # ORM 모델
│   ├── enums.py
│   ├── user.py
│   ├── attendance.py
│   ├── game_log.py
│   ├── gamble_log.py
│   └── point_history.py
├── crud/             # DB 조작 함수
│   ├── user_crud.py
│   ├── attendance_crud.py
│   └── game_log_crud.py
└── schemas/          # Pydantic 스키마 (입출력 검증)
    ├── user_schema.py
    └── game_log_schema.py
alembic/              # 마이그레이션
alembic.ini
```

## DB 테이블

| 테이블 | PK | 설명 |
|--------|-----|------|
| `user` | `user_id` (Discord ID, bigint) | 유저 정보, 포인트 잔액 |
| `attendance` | `attendance_id` | 출석 기록. `(user_id, date)` unique |
| `game_log` | `game_log_id` | 게임 결과 기록 |
| `gamble_log` | `gamble_log_id` | 도박 결과 기록 (미구현) |
| `point_history` | `point_history_id` | 포인트 변동 전체 이력 |

## 세션 사용 패턴

봇 Cog에서 직접 `SessionLocal`을 사용한다.

```python
async with SessionLocal() as session:
    user = await get_user(session, ctx.author.id)
    # ... 작업
    await session.commit()
```

## 포인트 변경 원칙

모든 포인트 변경은 `_apply_point()`를 통해 처리한다.
`user.point` 수정 + `PointHistory` 추가가 항상 같은 트랜잭션에 묶인다.

```python
def _apply_point(session, user, amount, reason):
    user.point += amount
    session.add(PointHistory(user_id=user.user_id, amount=amount, reason=reason))
    # 커밋은 호출자가 담당
```

## 마이그레이션 명령어

```bash
# 변경사항 감지해서 파일 생성
alembic revision --autogenerate -m "설명"

# DB에 적용
alembic upgrade head

# 롤백
alembic downgrade -1
```
