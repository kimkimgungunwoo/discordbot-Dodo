# 도도 폭탄전

갱신일: 2026-10-12. 첫 플레이 가능한 버전을 구현했다. 기존 도도새 스프라이트와 기존 게임의 크림색·짙은 초록·회녹색 UI를 사용한다.

## 진입과 대기방

- PC 전용. `/bomb-battle`은 로그인 없는 봇 연습, `/bomb-battle?room=...`은 Discord OAuth 온라인 대전이다.
- Discord에서 `!게임 폭탄전` 또는 `!게임` 메뉴의 폭탄전을 선택한다. 폭탄게임·폭탄도 명령어 별칭으로 사용할 수 있다.
- 사람과 봇을 합쳐 2~4인 개인전이다. 방장은 사람이며, 대기방에서 참가·참가 취소·봇 추가·봇 제거·시작·관전·방 닫기를 사용할 수 있다.
- 봇은 쉬움·보통·어려움·극한까지 지원한다. 방장만 봇을 변경하고 경기를 시작할 수 있다. 사람 1명 + 봇 1명으로도 시작할 수 있다.
- 연습에서는 인원·각 봇의 난이도·맵 패턴을 선택할 수 있다. 온라인 경기는 모든 사람 참가자가 접속하면 3초 카운트다운 후 시작한다.
- 경기는 한 라운드이며 마지막 생존자가 승리한다. 같은 틱의 동시 전멸과 2분 종료 시 여러 명 생존은 무승부다. 경기 종료 즉시 결과 팝업이 열린다. 사람 참가자 전원이 재시작에 투표하면 같은 방과 같은 참가자로 다음 경기를 시작한다. 봇과 관전자는 투표하지 않으며, 사람 1명 + 봇 구성은 사람 한 명의 투표로 시작한다. 결과 저장 중에도 투표는 가능하고 저장 완료 후 재시작한다.

## 조작과 판정

- 캐릭터는 소수점 좌표로 매 틱 연속 이동한다. 키를 떼면 멈추고 이동 중에도 방향을 즉시 바꿀 수 있다. 대각선 이동은 없고 동시에 누른 방향은 마지막 키를 우선한다. 캐릭터의 이동 충돌 몸통은 한 칸 폭의 36%(반경 0.18칸)로 작게 잡아 골목에서 여유 있게 움직인다. 벽·상자·폭탄은 이 몸통을 기준으로 통과를 막는다. 폭탄 설치·피격·아이템 획득은 캐릭터 중심이 속한 격자 칸을 기준으로 한다.
- Space를 누를 때 현재 칸에 폭탄 한 개를 설치한다. 키 자동 반복은 무시하며, 같은 틱에는 설치 후 이동한다.
- 플레이어끼리는 통과하거나 같은 칸에 있을 수 있다. 고정 벽은 파괴 불가, 파괴 상자는 폭발을 맞으면 부서지며 그 폭발은 해당 칸에서 멈춘다.
- 폭발은 상하좌우로 진행한다. 고정 벽에는 진입하지 않고, 다른 폭탄을 만나면 해당 칸에서 멈추며 연쇄 폭발을 일으킨다.
- 같은 틱의 모든 폭발은 같은 벽 배치를 보고 범위를 계산한 뒤 벽을 제거한다. 막 부서진 상자 뒤로 다른 폭발이 통과하지 않는다.
- 설치 순간 같은 칸에 있던 생존자는 폭탄에서 빠져나갈 수 있다. 한 번 나가면 해당 폭탄이 통행을 막는다.
- 피격 즉시 탈락한다. 도도새가 0.2초 동안 뒤집히며 눈을 감고 별이 도는 기절 모습이 된다. 피격 후 정확히 5초가 지나면 유령으로 전환한다.
- 경기가 진행 중이면 유령도 방향키로 돌아다닐 수 있고 내부 벽을 통과한다. 폭탄 설치·아이템 획득·승패에는 관여하지 않는다. 경기 종료 후에도 기절 → 유령 연출은 완료한다.
- 창 포커스를 잃거나 연결이 끊기면 이동을 중립으로 돌린다.

## 초기 템포와 아이템

플레이하며 조정할 수 있는 구현 기본값이다.

| 항목 | 기본값 |
| --- | --- |
| 맵 | 13×11칸, 매 경기 시드 기반 대칭 랜덤 배치·상자 밀도 4종 |
| 이동 | 60Hz 연속 이동, 약 5.8칸/초, 칸별 이동 대기시간 없음 |
| 폭탄 지연 | 120틱, 2초 |
| 폭발 유지 | 18틱, 300ms |
| 시작 능력 | 동시 폭탄 1개, 각 방향 범위 2칸 |
| 능력 상한 | 동시 폭탄 5개, 각 방향 범위 6칸 |
| 아이템 생성 | 1초마다 1개, 맵에 최대 8개 |
| 아이템 종류 | 폭탄 수 +1 / 각 방향 범위 +1, 각각 50% |
| 제한 시간 | 카운트다운 이후 2분 |

- 아이템은 맵 전체의 빈 바닥 중 무작위로 생성한다. 고정 벽·상자·폭탄·활성 폭발·기존 아이템·플레이어가 있는 칸에는 생성하지 않는다. 상자를 부술 때 나오는 아이템은 없다.
- 생성할 칸이 없거나 8개가 남아 있으면 해당 생성 기회를 건너뛰고 다음 주기에 다시 시도한다.
- 아이템은 폭발에 소멸하며 폭발을 막지 않는다. 같은 틱에 폭발과 획득이 겹치면 폭발이 우선한다.
- 능력 상한에 도달한 종류의 아이템도 소비한다. 추가 능력 증가는 없다.
- 아이템 위치·종류는 서버의 결정적 난수 상태에서 선택하고 확정 상태로 전달한다.

- 바닥 타일 무늬와 돌 위치는 경기마다 달라진다. 일부 맵에는 2×2칸의 큰 바위가 등장하며 네 칸 모두 이동·폭발을 막는다. 경기 중 바위는 움직이지 않는다.
- 모든 시작 지점의 3×3 공간을 비우며, 파괴 상자를 제거했을 때 모든 통로가 연결되는 배치만 사용한다.

## 온라인 예측과 서버 판정

- 서버가 60Hz로 이동·설치·폭발·아이템·봇·탈락·승패를 판정한다. 모든 참가자의 입력을 기다리는 배구 중계 방식과 달리, 입력이 없는 참가자는 가만히 있고 전체 경기는 계속 진행한다.
- 본인의 이동과 설치는 응답을 기다리지 않고 화면에 예측한다. 배구처럼 서버 확정 상태에 아직 처리되지 않은 입력을 다시 적용하며 최대 12틱(200ms)까지 예측한다.
- 조작 캐릭터는 서버와 동일한 연속 충돌 규칙으로 미확정 입력을 예측하며 표시 보간 지연을 적용하지 않는다. 예측 중 상대의 탈락이나 경기 종료를 확정하지 않는다.
- 서버는 입력 시퀀스의 수신·처리 번호를 전달한다. 폭탄은 설치 입력 번호로 대응시켜 중복 표시·재실행을 막는다.
- 입력은 방향 상태와 설치 단발 이벤트로 구분한다. 방향키 변경 때 즉시 전송하고 100ms마다 갱신한다. 30틱(500ms) 동안 새 입력이 없으면 이동을 중립으로 처리한다.
- 온라인 상대·봇은 약 67ms의 표시 버퍼에서 서버 스냅샷 좌표를 보간한다. 로컬 봇은 매 틱 연속 좌표를 표시한다. 탈락과 결과는 서버 확정 상태만 사용한다. 일반 스냅샷은 20Hz, 주요 이벤트·입퇴장 시에는 즉시 전달한다.
- 관전과 재접속은 현재 전체 상태를 받으며 과거 경기 전체를 재생하지 않는다. 재접속 시 미확정 로컬 입력은 비우고 서버 입력 번호부터 이어간다.
- 관전자 최대 50명과 참가자 최대 4자리를 별도로 확보한다. 관전자 입력 및 클라이언트 결과 보고는 무시한다.
- 입력 예측은 핑을 없애지 않는다. 높은 지연에서 충돌·위치·설치 화면이 서버 상태로 보정될 수 있다. 서버 재시작 시 진행 중인 방은 유실된다.

## 봇

- 모든 봇은 사람과 같은 이동·폭탄 개수·범위·아이템·피격 규칙을 따른다.
- 모든 난이도에서 현재 폭탄과 연쇄 폭발·잔여 불꽃을 끝까지 예측한다. 위험 칸에서는 난이도별 판단 지연보다 탈출을 우선한다.
- 설치 전에 가장 빨리 도달할 수 있는 안전한 대피 칸을 찾고, 설치 후에는 아이템·공격 목표보다 탈출을 우선한다. 자기 폭탄이 남아 있으면 대피 위치를 지키고, 잔여 불꽃은 위험 예측에 포함해 피한다. 다른 곳의 불꽃 때문에 맵 전체의 봇이 멈추지는 않는다.
- 쉬움·보통은 안전한 상태에서의 판단 주기와 주기적 대기로 차이를 둔다. 어려움·극한은 이동 가능할 때 즉시 판단한다. 모든 난이도가 상대를 공격할 수 있는 사거리 내 빈칸으로 접근하며, 극한은 공격 목표를 더 우선한다.
- 다른 플레이어가 새 폭탄으로 통로를 막는 등 새 위험이 생기면 탈출 경로를 다시 계산한다. 피할 수 없는 외부 공격까지 무적처럼 회피하는 것은 아니다.

## 디자인과 코드

- `games/client/src/common/sprites.ts`의 도도새 idle·run·lose 그림을 참가자별 목도리 색으로 사용한다. 기존 스프라이트를 새 그림으로 교체하지 않았다.
- 중앙 맵, 상단 단판 표시·생존자·시간, 오른쪽 참가자·폭탄·범위, 아래 조작·관전·소리 안내를 둔다.
- `games/shared/bomb-battle.ts`: 공통 격자 규칙과 결정적 상태 진행.
- `games/shared/bomb-battle-bot.ts`: 미래 폭발과 시간 경로 탐색 봇.
- `games/server/src/bomb-battle-room.ts`: 고정 틱·인증된 입력·스냅샷·결과·재접속.
- `games/client/src/bomb-battle/`: 조작·예측·기존 도도새 기반 렌더링·연습 화면.
- `bot/cogs/game/bomb_battle.py`: 다인 대기방과 결과 검증. 전적은 모든 사람·봇 좌석을 저장하고, 사람의 승·무·패를 집계한다. 첫 버전은 별도 레이팅 증감을 적용하지 않는다.

## 실행 및 검증

- 개발 서버에서 `/bomb-battle`을 열면 바로 봇 연습을 할 수 있다.
- 온라인은 기존 Activity 서버·봇을 갱신하고 Discord OAuth Redirects에 운영 도메인의 `/bomb-battle` 및 필요한 로컬 주소를 등록해야 한다.
- DB 연결 시 봇 시작 과정에서 `api/dodo/schema.sql`의 폭탄전 테이블·게임·규칙 세트를 추가한다. 운영 Caddy의 게임 경로에도 `/bomb-battle`을 연결했다.
- 빌드: `games/client`, `games/server`에서 각각 `npm run build`.
- 규칙·봇·예측·네트워크: `games/server/node_modules/.bin/tsx --test games/server/tests/bomb-battle*.test.ts`.
- 봇 대기방·저장: `discordvenv/bin/python -m unittest bot.cogs.game.test_bomb_battle api.dodo.test_bomb_battle`.
- 대칭 맵·시작 안전성·연결성, 벽 차단·동시 연쇄 폭발, 아이템 생성·소멸·상한, 동시 전멸·시간 종료·5초 유령 전환, 설치 중복·입력 만료·관전·재접속·서버 결과 콜백을 자동 검증한다.
- 실제 Discord 사용자 여러 명의 OAuth 접속과 체감 밸런스는 추가 확인이 필요하다.

- 짧은 방향키 누름·뗌이 서버의 같은 틱 사이에 도착해도 한 틱 이동으로 반영한다. 칸 이동 예약이나 이동 대기시간은 없다. 내 위치는 머리 위 화살표로 표시하며, 유령은 사각 배경 없는 반투명 스프라이트다.
