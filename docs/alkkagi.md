# 도도새 알까기

`!게임 알까기` 또는 게임 메뉴에서 봇전/대결을 선택한다. `/alkkagi`는 CPU 연습, `?room=...`은 Discord 온라인 방이다. OAuth Redirects에 공개 도메인의 `/alkkagi`를 등록한다.

기존 오목판과 화면을 사용한다. 흑백 각 6개씩 대칭 배치하며 흑 선공이다. 자기 돌을 누르고 발사 반대 방향으로 드래그한 뒤 놓는다. 짧은 화살표는 발사 방향과 대략적인 힘만 보여준다. 당기는 거리는 최대 힘에서 제한하며, 거의 당기지 않으면 취소된다. Esc와 터치 취소도 지원한다.

같은 질량의 원형 돌이 충돌하고 일정 마찰로 멈춘다. 일반 발사 속도는 당긴 길이에 비례해 최대 940이며, 최대 길이 150까지 당겼을 때만 발사 속도가 1200으로 증가한다. 마찰 감속은 1050이다. 모든 충돌은 동일한 반발 계수 1.3을 사용해 정면 충돌 시 맞은 돌의 밀림과 쏜 돌의 반동을 강화한다. 반발 계수가 1보다 크므로 게임식 힘 증폭이 적용된다. 60Hz마다 4번의 물리 계산을 수행해 빠른 돌의 충돌 누락을 줄인다. 돌 중심이 보드 밖으로 나가면 탈락하며 자신의 돌도 탈락한다. 모든 돌이 멈춘 뒤 차례를 넘긴다. 상대 돌이 모두 탈락하면 승리, 동시 전멸은 무승부다. 40턴 연속 탈락이 없으면 무승부로 종료한다. 45초 동안 발사하지 않으면 서버가 가까운 상대 방향으로 자동 발사한다.

서버가 발사 벡터와 힘, 차례, 경기 버전을 검증하고 모든 물리·승패를 계산한다. 이동 상태를 20Hz로 전송하며 클라이언트는 동일 물리로 최대 3틱 화면 예측을 수행한다. 중도 관전/재접속은 현재 위치·속도를 복원한다. 움직이는 도중 연결이 끊겨도 해당 발사는 서버에서 마저 처리하며 다음 차례는 참가자 재접속을 기다린다.

봇은 쉬움·중간·어려움·극한 4단계다. 쉬움은 조준과 힘에 오차를 주고, 중간은 여러 실제 발사 결과를 비교한다. 어려움은 후보를 늘리고 상대의 반격을 계산한다. 극한은 최대 4.5초 동안 거리별 충돌각과 마찰·반발을 고려한 힘, 미세 각도/힘 보정, 상대 반격과 자신의 회복 수를 탐색한다. 돌 수, 가장자리 위험, 경기 종료를 평가하며 자신의 실제 돌로 같은 물리를 사용한다. 제한된 후보와 시간 안에서 탐색하므로 전수 계산이나 특정 명중률을 보장하지 않는다. 서버 계산은 동시 2개 이하 워커와 대기열로 제한하고, 로컬 연습도 워커를 사용한다.

기존 방 생성·참가·관전·재경기·결과 재전송을 사용한다. PostgreSQL의 공통 경기/참가자/통계 구조에 연결하며 `alkkagi_match`에 양측 남은 돌 수를 기록한다. 전적 화면은 오목처럼 승·무·패, 승률, 최고 연승, CPU 난이도별 전적과 PVP Elo/랭킹을 표시한다. 진행 상태는 메모리에 보관하며 서버 재시작 시 복원하지 않는다.
