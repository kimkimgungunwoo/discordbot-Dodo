# 증강마블 기본판

## 실행

- 개발 클라이언트의 `/augment-marble`: 2~4인 연습, 본인 외 도도봇.
- Discord `!게임 증강마블` 또는 게임 메뉴의 증강마블: 기존 서버 판정 방식으로 2~4인 대전. 봇 추가, 관전, 재접속, 결과 저장, 재경기 투표 지원.
- 운영 반영 시 `api/dodo/schema.sql`을 기존 방식으로 적용하고 서버·봇·클라이언트를 갱신한다. Discord OAuth redirect 목록에 해당 도메인의 `/augment-marble` 경로를 등록해야 한다.
- 진행 상태는 다른 턴제 게임처럼 서버 메모리에 보관한다. 서버 재시작 시 영속 체크포인트에서 경기·제한 시간·미완료 결과를 복원한다. 운영에서는 `MARBLE_STATE_DIR`의 영속 볼륨을 유지한다.

증강 선택 틀과 세부 규칙은 [augment-marble-augments.md](augment-marble-augments.md)에 정리한다. 실제60개 카드가 활성화되어 있다. 효과·추가 규칙은 [augment-marble-abilities.md](augment-marble-abilities.md)를 따른다.

## 보드

사용자 제공 이미지의 36칸을 그대로 배치한다. 우하단 출발에서 하단 왼쪽, 좌변 위쪽, 상단 오른쪽, 우변 아래쪽 순서로 이동한다.

```
출발 A1 A2 A3 A4 이벤트 B1 B2 B3
휴식 B4 C1 C2 C3 이벤트 C4 D1 D2
이벤트 D3 D4 E1 E2 보너스 E3 E4 F1
보너스 F2 F3 F4 G1 이벤트 G2 G3 G4
```

각 행은 모서리에서 시작하는 한 변이다. A~G 그룹은 각각 4개 도시이며 B/D/F는 모서리를 걸친다. 관광지·우주여행은 없다. 증강은 개인 출발선 통과 기준으로 획득한다. 이벤트는 [33종 이벤트 규칙](augment-marble-events.md)에 따라 한 개를 추첨하고 필요한 대상만 선택한다.

## 경제와 기본 규칙

최신 가격표와 세금 규칙은 [augment-marble-economy-v2.md](augment-marble-economy-v2.md)를 따른다.

- 시작 현금300 / 월급100 / 보너스20만원.
- 지역은 A1의 20만원부터 G4의 128만원까지 4만원씩 상승한다. 건설비와 통행료 가산도 그룹별로 다르다.
- 토지 기본 통행료는 가격의 1/5 올림이다. 별장·빌딩·호텔은 각각 최대1개이며 첫 방문부터 독립적으로 선택 건설한다.
- 색상 그룹4개 소유 시 통행료2배, 그룹3개 완성 또는 한 변의 모든 도시 소유 시 즉시 승리한다. 최후 생존도 승리다.
- 상대 지역에서 통행료 지급 후 토지·현재 건물 정가 합계의 2배로 인수한다. 건물은 유지되며 그 방문에는 건설할 수 없다.
- 출발 통과·정확한 도착 때 월급100을 받고 보유 토지가 합계의5%를 합산 후 올림해 납부한다. 건물은 과세하지 않는다. 기존 세금 칸은 빈 이벤트 칸으로 바뀌었다.
- 현금 부족 시 토지와 건물을 함께 은행에 정가의50%로 매각한다. 지급 불가능하면 파산하고 잔여 청산가액을 채권자에게 정산한 뒤 지역을 무주지로 돌린다.
- 더블은 추가 행동, 3연속 더블은 휴식 칸 이동과 다음 자기 차례1회 휴식이다. 휴식 칸 정상 도착도 다음 차례1회 휴식이다.
- 행동 제한45초, 증강 선택30초다. 시간 초과 시 단계별 기본 행동을 자동 처리한다. 모든 사람이 연결을 종료하면5분 후 중단한다.

## 턴과 라운드

- 턴은 플레이어 한 명의 차례 전체다. 주사위·이동·구매·건설·인수·정산과 더블 추가 행동을 포함한다.
- 라운드는 생존한 참가자 전원이 턴을 한 번씩 마친 주기다. 1라운드·1턴으로 시작하며 마지막 참가자의 턴이 끝나면 다음 라운드로 넘어간다.
- 더블의 추가 주사위는 같은 턴·같은 라운드다. 휴식으로 쉬는 차례도 턴을 완료한 것으로 센다.
- 파산한 참가자는 남은 순서에서 제외한다. 중간에 파산자가 생겨도 아직 턴을 진행하지 않은 생존자의 차례를 건너뛰지 않는다.
- 초기 증강 선택은 턴·라운드를 소모하지 않는다. 출발 통과 증강 선택·채무 정산도 현재 턴 안에서 처리한다.
- 화면에는 현재 라운드와 경기 전체의 누적 턴 번호를 함께 표시한다. 이동으로 출발선을 도는 개인 바퀴 수는 별도다.
- 월급·토지세·증강 획득 조건은 기존처럼 개인 출발선 통과 기준이며 라운드와 무관하다.

## 결과

승리자는 상대 수 × 10점, 나머지는 각 -10점이다. 연습은 저장하지 않는다. 온라인 결과는 `marble-augments-v2` 규칙, 좌석별 전적과 점수, `marble_match`의 승리 사유에 저장한다. 재경기는 사람 참가자 전원 동의와 결과 저장 완료 후 진행한다.

## 검증

- 규칙/방 테스트: 맵 구성, 출발 월급, 특수 칸, 건설, 통행료, 인수, 두 독점 조건, 파산·매각, 더블, 입력 검증, 재접속, 봇 자동 대전 30개 시드.
- HTTP/WebSocket 테스트: 대기방 전달, 서버 주사위, 잘못된 프로토콜 차단, 관전, 오래된 요청 차단, 재접속, 방 닫기.
- Python 테스트: Discord 대기방과 링크, 결과 검증, 봇 승리와 사람 패배, 중복 저장 방지, 중단 처리.

120라운드가 모두 끝나면 생존자 자산 순위로 종료한다. 랜드마크와 휴식 해제, 증강 수치는 능력 문서를 따른다. 스키마 갱신은 새 승리 사유 `assets` 제약과 새 규칙 버전을 포함하므로 서버·봇 갱신 전에 적용한다.
