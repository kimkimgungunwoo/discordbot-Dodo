# 도도새 오델로

`!게임 오델로` 또는 게임 메뉴에서 봇전/대결을 선택한다. `/othello`는 로그인 없는 CPU 연습, `?room=...`은 Discord 인증을 사용하는 온라인 경기다. Discord 앱의 OAuth Redirects에 공개 도메인의 `/othello`를 등록해야 한다.

기존 오목의 화면, 도도새 픽셀 그림, 관전 및 재경기 흐름을 사용한다. 빨강/파랑 오각형 토큰이며 빨강이 선공이다. 착수는 즉시 표시하고 뒤집히는 돌만 300ms 동안 동전처럼 회전한다. 중도 관전과 재접속은 현재 보드를 즉시 복원한다.

8×8 표준 규칙: 중앙 4개로 시작, 8방향 포위 판정, 합법 수 없는 진영 자동 패스, 양쪽 모두 합법 수 없으면 종료한다. 최종 돌 개수로 승패를 정한다. 서버가 모든 착수와 결과를 판정하며 45초 초과 시 합법 수를 무작위 선택한다. 진영은 오목처럼 경기마다 추첨한다.

봇은 오목과 같은 5단계다. 쉬움은 무작위, 중간은 최대 2수/60ms, 어려움은 5수/250ms, 극한은 9수/1.2초(빈칸 12개 이하 종반에는 종료까지 탐색 시도), 초월은 최대 16초/종료까지 반복 심화 탐색한다. 모서리, 빈 모서리 인접 위험 칸, 가장자리, 상대 착수 가능 칸을 평가한다. 예산 내에 완료된 깊이만 채택하며 무패를 보장하지 않는다. 어려움 이상은 서버 워커와 제한된 대기열에서 계산하고 브라우저 연습도 워커를 사용한다.

PostgreSQL에 최종 양측 돌 수와 착수 수를 저장한다. 기존 승패/연승, CPU 난이도별 통계, PVP Elo와 서버/전체 랭킹에 연결한다. 게임 상태는 기존 게임과 동일하게 메모리에 보관한다.

`!게임 통계`에서 오델로 봇전 또는 대결을 고른 뒤 `내 전적`으로 오목과 동일하게 승·무·패, 승률, 최고 연승, PVP 레이팅을 조회한다. 봇전은 난이도별로 분리하며 서버/전체 랭킹을 지원한다. 중단 경기는 통계에서 제외하며 동일 match_id는 중복 합산하지 않는다.
