# 유저 포인트 시스템

## 개요
Discord 유저를 DB에 등록하고, 출석/게임을 통해 포인트를 쌓는 시스템.
모든 포인트 변동은 `point_history` 테이블에 이력이 남는다.

## 명령어 목록

| 명령어 | 조건 | 동작 |
|--------|------|------|
| `!등록` | 미등록 유저 | 유저 생성 + 1,000P 지급 |
| `!정보` | 등록 유저 | 닉네임·포인트·가입일 임베드 |
| `!출석` | 등록 유저, 1일 1회 | 1,000P / 4% 확률 2,000P |
| `!게임기록` | 등록 유저 | 최근 5판 전적 + 승률 |

## 포인트 지급 경로

| 행동 | 금액 | PointReason |
|------|------|-------------|
| 최초 등록 | +1,000P | `admin` |
| 출석 (일반) | +1,000P | `attendance` |
| 출석 (잭팟 4%) | +2,000P | `attendance` |
| 게임 승리 | +100P | `game_win` |
| 게임 패배 | -100P | `game_lose` |

## 중복 방지

- **등록**: `get_user()`로 존재 여부 확인 후 이미 있으면 거절
- **출석**: `(user_id, attendance_date)` unique 제약 + `get_today_attendance()`로 사전 확인

## `!정보` 임베드 구성

- 타이틀: 서버 닉네임 (`ctx.author.display_name`)
- 썸네일: 서버 프로필 사진 (`ctx.author.display_avatar.url`)
- 필드: 💰 포인트, 📅 가입일

닉네임과 프로필 사진은 DB에 저장하지 않고 명령어 실행 시점에 Discord에서 실시간으로 가져온다.
