# 증강마블 증강 목록

현재 프로젝트 코드 기준의 활성 증강 **57개**입니다. 실버 **17개**, 골드 **22개**, 프리즘 **18개**로 구분합니다.

> [!info] 획득 규칙
> 기본 선택은 게임 시작 전과 개인 출발선 1·3·5회 통과 시 총 4회입니다. 30라운드 시작 시 생존자 모두가 프리즘 증강을 동시에 한 번 더 선택합니다. 추가 선택은 기본 획득 회차를 소비하지 않습니다. 선택 시간은 30초이며 각 카드 위치는 한 번씩 리롤할 수 있습니다.

> [!note] 현재 등급 조정
> 선택적 더블·따라쟁이·월급 인상·전업투자자·김씨표류기는 골드입니다. 더블애호가·페이백·방귀쟁이는 실버입니다. 힘조절 3종은 삭제되어 이 목록에 포함하지 않습니다.

## 공통 적용 기준

- 금액 단위는 만원입니다. 기본 월급은 250만원입니다.
- 착취는 같은 라인의 유효 대상 수로 15%를 나눕니다. 면역으로 제외되는 상대는 분모에 포함하지 않으며, 모서리의 상대를 중복 계산하지 않습니다.
- 재방문 특혜는 건물 3종이 완공된 자기 지역에 다시 도착할 때 통행료 가산이 40%씩 누적되는 공통 규칙입니다. 횟수 제한이 없고 인수 후에도 유지됩니다.
- 컬러독점 통행료 2배는 현재 소유 상태로 다시 계산합니다. 이전 소유자의 도박사 배율은 인수 시 해제되고, 인수자도 해당 능력을 보유했다면 새로 추첨합니다.
- 최대 60라운드이며, 컬러독점 2개·라인독점·최후 생존 중 하나를 달성하면 즉시 승리합니다.
