# 증강마블 이벤트 33종

2026-11-11 사용자가 제공한 목록과 후속 확정을 반영한다. 이벤트 칸에 도착하면 **이벤트 하나를 추첨**한다. 증강처럼 후보 카드 여러 장을 보여주거나 이벤트 종류를 선택하지 않는다. 추첨에서 이전에 나온 이벤트를 제외하지 않으므로 같은 이벤트가 반복될 수 있다.

## 추첨과 선택 시간

- 기본 분류 확률은 긍정·중립·부정 각 1/3이며 분류 안의 11개는 균등 추첨한다.
- 행운!은 부정 확률을 절반으로, 운수대통은 0으로 만든다. 제거된 확률은 긍정·중립에 균등 분배한다.
- 추첨 결과는 하나의 결과 패널로 표시한다. 필요한 대상·지역·라인·칸 수·교체 증강·베팅액만 선택한다.
- 이벤트 적용과 대상 선택은 30초. 시간이 지나면 기본 대상·라인을 적용한다. 영웅출현·증강변경은 사용 포기, 도박은 0원으로 처리한다. 나머지 이벤트는 거부할 수 없다.
- 도착지의 매입·건설·인수·채무 정산은 단계당 기존 행동 시간 45초를 사용한다. 해당 플레이어에게 조작권을 넘긴 뒤 남은 방문자를 처리하고 원래 차례로 돌아온다.
- 서버는 참가자·턴 ID·상태 리비전과 이벤트 일련번호를 검증한다. 잘못된 선택이나 재접속이 추첨을 바꾸거나 제한 시간을 초기화하지 않는다.

## 반복·지속 시간

- 하이패스 쿠폰·귀환석·한번더 쿠폰은 개수를 누적한다.
- 다음 월급 삭감·월급 체불·수면·주사위 분실·역주행·다음 손실 2배는 횟수를 누적한다. 배율을 반복해서 곱하지 않는다.
- 경제대공황과 임금체불은 같은 월급에 함께 소모한다. 체불로 0원을 받아도 반감 1회도 함께 소모한다.
- 흉년과 무능력자는 획득 라운드+3 라운드가 시작될 때 만료한다. 반복 시 종료 시점을 갱신한다.
- 과소비는 획득 후 다음 자기 차례 3회에 적용한다. 본인이 내는 통행료를 1.5배로 만들고 소유자도 실제 증가한 금액을 받는다. 반복 시 기간을 갱신한다.
- 무능력 중 새로 얻은 증강의 획득 효과는 정지 종료 라운드까지 대기한다. 그 전에 교체한 카드는 실행하지 않는다.
- 기면증·마취총의 수면은 다음 정상 자기 차례에서 소모한다. 더블 추가 투척은 다음 차례로 세지 않는다.
- 무능력자는 획득한 본인의 증강만 중단한다. 소유 목록은 유지하고 효과 조회·사용·스텔스와 설치물 발동 등을 차단한다.
- 축제는 같은 지역에 반복되면 2배씩 중첩하며 다음 상대의 첫 방문에서 모두 소모한다. 면제 쿠폰을 쓰더라도 방문으로 소모한다.
- 메뚜기떼는 지나간 지역에 0.7배씩 누적하고 경기 종료까지 유지한다. 소유권 변경에도 유지한다.

## 이동·벽·파괴

- 염력·태풍·바보출현은 도착 효과를 적용하고 매입·건설·인수를 허용한다. 여러 플레이어는 순서대로 선택한다.
- 이런 이벤트 이동 중 출발을 지나거나 정확히 도착해도 출발선 월급·세금·바퀴 수·증강 선택은 발동하지 않는다. 귀소본능과 귀환석만 명시된 예외다.
- 귀환석은 자기 차례 투척 전 사용한다. 월급만 받고 차례를 종료한다. 사용 후 한번더 쿠폰으로 다시 움직일 수 없다.
- 한번더 쿠폰은 자기 이동·도착 처리 뒤 추가 투척에 사용한다. 주사위 능력은 사용 가능하되 선택적 더블의 첫 투척 조건은 그대로 유지한다.
- 벽은 두 칸 사이의 경계를 양방향으로 막는다. 벽 직전 칸에 정지해 그 칸의 효과를 적용하고 벽은 사라진다. 같은 경계에 벽을 중복 설치할 수 없다.
- 영웅출현은 대상 위치로 이동하되 도착 효과를 생략한다. 웜홀은 다른 이벤트 칸으로 이동하되 새 이벤트를 뽑지 않는다.
- 건물 파괴는 랜드마크를 먼저 제거하고, 일반 건물은 호텔→빌딩→별장 순으로 하나를 제거한다. 빈 지역은 지진 영향을 받지 않고 미사일만 소유권을 없앤다.
- 도박은 보유 현금 이하의 정수 금액을 베팅한다. 성공 시 원금은 유지하고 같은 금액을 수익으로 받으며, 실패 시 베팅액을 잃는다. 기존 수입·손실 배율도 적용한다.
