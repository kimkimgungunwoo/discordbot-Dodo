# 게임 로그 기능

## 개요
게임(참참참, 가위바위보) 결과를 DB에 기록하고,
`!게임기록` 명령어로 최근 5판 전적과 승률을 조회한다.

## 관련 파일

| 파일 | 역할 |
|------|------|
| `api/models/game_log.py` | GameLog ORM 모델 |
| `api/models/enums.py` | GameType enum |
| `api/crud/game_log_crud.py` | DB 조작 함수 |
| `api/schemas/game_log_schema.py` | 응답 스키마 |
| `bot/cogs/game.py` | 게임 플레이 + 로그 기록 |
| `bot/cogs/user.py` | `!게임기록` 명령어 |

## GameLog 모델

```python
class GameLog(Base):
    game_log_id : int (PK, autoincrement)
    user_id     : bigint (FK → user.user_id)
    game_type   : GameType enum
    result      : str  # "승리" / "패배" / "비김"
    point       : int  # +100 / -100 / 0
    created_at  : datetime
```

## 스키마 구조

```
GameLogListInfo
├── user: UserInfo          # user_schema.UserInfo 재활용
│   ├── user_nickname: str
│   ├── point: int
│   └── created_at: datetime
├── game_log_list: list[GameLogInfo]
│   ├── game_type: GameType
│   ├── result: str
│   └── point: int
└── win_rate: float
```

`UserInfo`를 재활용해서 유저 정보 스키마 중복을 피했다.

## 포인트 규칙

| 게임 | 승리 | 비김 | 패배 |
|------|------|------|------|
| 참참참 | +100P | — | -100P |
| 가위바위보 | +100P | ±0P | -100P |
| 제비뽑기 | +100~+500P (60%) | — | -100~-700P (40%) |

## CRUD 함수

```python
# 게임 결과 저장 (point 변경 + history 기록 포함)
async def create_game_log(session, user, game_type, result, point) -> GameLog

# 최근 N판 조회 (created_at DESC)
async def get_recent_game_logs(session, user_id, limit=5) -> list[GameLog]
```

## `!게임기록` 출력 형식

코드블록 테이블로 출력. 한글 전각 문자(2칸) 너비를 `unicodedata.east_asian_width`로 보정해서 정렬을 맞춘다.

```
 #  게임          결과  포인트
──────────────────────────────
 1  가위바위보    승리   +100P
 2  참참참        패배   -100P
 3  참참참        승리   +100P
```

## 등록 유저 전용

미등록 유저가 게임 버튼을 누르면 `!등록` 안내 메시지를 띄우고 중단한다.

```python
async def _require_user(interaction, session):
    user = await get_user(session, interaction.user.id)
    if user is None:
        await interaction.response.edit_message(
            content="`!등록` 명령어로 먼저 등록해주세요.",
            embed=None, view=None,
        )
    return user
```
