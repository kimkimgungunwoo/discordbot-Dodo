# 증강마블: 봇 준비 및 능력·이벤트·화면 점검

검토일: 2026-11-11. 원본 60개 증강과 이벤트 33개를 유지하면서 실제 동작 충돌을 재현하고 수정했다. 새로운 고급 봇 전략을 완성했다는 의미는 아니다.

## 재현 후 수정한 문제

| 구분 | 문제 | 수정 결과 |
|---|---|---|
| 봇 판단 | `autoAction()` 호출만으로 시작 능력이 발동하고 현금·상태가 변경됨 | 복제 상태에서 판단하며 실제 상태는 `applyAction()`에서만 변경 |
| 봇 비용 | 유리대포·면역력 감소로 비용이 증가해도 무인도를 기본 300만원으로 판단 | 실제 최종 매수 비용으로 가능 여부 판단 |
| 수면과 더블 | 현재 이동에서 얻은 기면증이 더블 추가 투척에서 즉시 소모됨 | 다음 정상 자기 차례 시작에 수면을 활성화; 현재 추가 투척에는 소모하지 않음 |
| 강제 통행료 | 신지드에 던져졌을 때 자동 하이패스 무시, 축제 미소모 | 자동 면제와 첫 방문 축제 소모 적용 |
| 수동 쿠폰 | 신지드 강제 통행료를 쿠폰 선택 없이 즉시 정산 | 대상 플레이어에게 쿠폰 선택을 넘기고 원래 차례로 복귀; 신지드의 매입·인수 금지는 유지 |
| 무능력과 무인도 | 비활성화된 김씨표류기 소유자가 휴식 비용을 강탈 | 능력이 실제 활성 상태일 때만 강탈 |
| 무능력과 획득 | 무능력 중 새 지급·전환 등 획득 효과가 즉시 발동 | 소유는 기록하고 획득 효과를 대기시킨 뒤 정지 기간 종료 라운드에 실행; 이미 교체한 카드는 제외 |
| 무능력과 도박 | 무능력 중 새로 매입한 지역의 도박 결과가 1배로 고정됨 | 추첨 결과는 저장하되 정지 중 배율은 적용하지 않고 해제 후 복구 |
| 이벤트 입력 | 같은 리비전의 접속 상태 갱신으로 대상·칸 수·베팅액이 초기화됨 | 같은 경기·이벤트 일련번호 안에서 입력과 포커스 유지 |
| 필수 선택 화면 | 규칙·능력 설명 창이 새 이벤트·쿠폰·채무 선택을 가림 | 본인에게 새 필수 선택이 오면 기존 설명 창 닫기 |
| 스텔스 이동 | 대기 말은 반투명인데 이동 복제 말은 불투명하게 표시됨 | 이동 복제 말에도 현재 불투명도 유지 |
| 비용 안내 | 휴식 해제 설명은 50만원인데 실제 손실 배율 반영 비용은 더 큼 | 설명·버튼·실제 비용 일치 |

## 검증 결과

- 마블 테스트 **162개 통과**. 기존 네트워크·저장·시간 제한·경제·연출 검사 포함.
- 단일 증강 획득 후 단일 이벤트를 처리하는 **1,980개 조합**에서 자동 행동 수용, 유효 소유권, 안전한 정수·비음수 잔액, 이벤트 처리 종료 검사.
- 2·3·4인 각각 증강 사용/미사용 조건에 60개 고정 시드, 총 **360경기** 실행. **미종료 0건**, 총 **302,139개 행동**. 예외·음수 현금·파산자 소유권이 발생하면 분석 스크립트가 실패하도록 검사.
- 사람 2명과 봇 1명의 같은 방에서 이벤트가 봇을 이동시키고 봇이 자동 매입하는 실제 타이머 경로 검사. 사람의 봇 차례 조작은 거부.
- 390px / 1440px 브라우저에서 이벤트 입력·포커스 유지, 선택값 유지, 필수 통행료 화면 노출, 이동 중 스텔스, 가로 넘침 확인.
- 서버·클라이언트 빌드 통과.

수치 결과는 [검증 결과 JSON](augment-marble-review.json)에 보존한다. 고정 시드의 반복 검사는 모든 다중 능력 조합, 모든 장기 이벤트 연쇄, 사람 상대 승률이나 경쟁적 밸런스를 증명하지 않는다.

## 플레이어와 함께할 봇 구현에 남은 전략 작업

현재 봇은 게임을 진행하는 기본 정책이다. 규칙 검증·서버 판정은 사람과 공유한다. 다음 항목은 진행 오류가 아니라 판단 품질의 과제다.

1. **이동 가치 평가:** 지금의 목적지 평가에 역주행·벽·통과 공격·상태 제한을 포함하고, 실제 이동 경로와 같은 규칙으로 예상 손익을 계산할 것.
2. **쿠폰 사용:** 현재 자동 통행료 선택은 보유 쿠폰을 바로 쓰는 단순 정책이다. 큰 통행료 대비 보존, 귀환석 사용, 한번더 쿠폰 사용을 정책화할 것.
3. **이벤트 대상:** 지진 라인·벽 경계·염력 거리 등을 기본값으로 고르는 부분을 상대 피해와 본인 손익 기준으로 평가할 것. 영웅출현의 이동 후 위험도도 평가할 것.
4. **증강 조합:** 고정 선호 순서를 소유 토지·현금·기존 증강·정지 상태를 반영하는 평가로 교체할 것. 증강변경의 기본 거부도 평가 기반으로 바꿀 것.
5. **위험 성향:** 현재 도박 기본값 0원을 유지할지 난이도별 베팅 정책을 추가할지 정할 것. 강제 시간 초과 처리와 봇의 전략 결정을 계속 분리할 것.
6. **정보 범위:** 미래 등급·타인의 비공개 선택지·난수 결과를 봇 판단에 사용하지 말 것. 현재 기본 판단도 이를 직접 읽어 선택하지 않는다.
7. **난이도:** 현재 자동 행동은 공통 기본 정책이다. 난이도별 정책과 사람 상대 성능은 별도 검증할 것.
