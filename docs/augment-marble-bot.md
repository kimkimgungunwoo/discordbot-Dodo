# 증강마블 전략 봇

> 최신 규칙: 컬러독점 2개 또는 라인독점으로 승리, 최대 60라운드. 힘조절 3종 삭제(활성 57종). 유리대포의 추가 수입·지출은 상대에게 전가하지 않고 은행 지급·소멸로 정산한다.


현재 봇은 `games/shared/augment-marble-bot.ts`의 공개 상태 기반 규칙 평가를 사용한다. 서버와 연습 모드는 같은 판단 코드를 공유한다. 경기 판정은 계속 `applyAction()`이 담당한다.

## 구현한 판단

- **현금 운용:** 보유 현금과 다음 이동 구간의 공개 통행료로 예비금을 정한다. 기본 월급의 3배 이상 현금이 있으면 여유 자금을 더 적극적으로 투자한다.
- **무인도:** 유료 탈출비와 예비금이 확보되면 기다리지 않고 탈출한다. 무인도 매수 능력과 충분한 현금이 있으면 매수하며 구금도 해제한다.
- **부동산:** 세 번째 바퀴부터 매입 직후 건물을 일괄 건설하고, 건물 3종이 이미 완공된 자기 지역에 다시 도착했을 때 랜드마크를 검토한다. 인수 직후에는 랜드마크를 짓지 않는다. 인수는 수익성·독점 완성·상대 승리 차단을 함께 평가한다.
- **포탈:** 단순한 고가 땅보다 승리·독점 완성·상대 독점 차단을 우선하며, 현금이 충분하면 이미 개발된 상대 지역도 노린다.

- **이동:** 실제 엔진에서 후보 주사위 결과를 모의 실행해 벽·역주행·통과 공격·통행료·채무·휴식·매입 기회를 평가한다. 미래 증강 제안은 모의 실행에서 제외한다.
- **주사위:** 힘조절 범위·더블 여부·따라쟁이·리롤을 비교한다. 수상한주사위는 각각 어느 주사위를 다시 던질지 비교하고 블랙다이스는 기존·새 결과를 비교한다.
- **쿠폰:** 작은 통행료에는 하이패스를 아끼고, 큰 청구·파산 위험에는 사용한다. 귀환석은 안전한 월급과 현재 경로 손익을 비교하고, 한번더 쿠폰은 유리한 추가 이동에 사용한다.
- **이벤트:** 염력의 대상·거리, 지진의 적군 피해와 아군 피해, 축제 지역, 벽 경계, 마취총·강도 대상, 영웅출현 이동 여부를 평가한다.
- **증강:** 현금·소유 지역·기존 능력·후반 진행도를 반영한다. 전업투자자가 있으면 월급 관련 능력의 가치를 낮춘다. 후보 품질이 낮으면 허용된 카드 리롤을 사용한다.
- **증강변경:** 가치가 낮은 보유 카드를 같은 등급 후보의 기대값과 비교한다.
- **도박:** 현금이 충분하고 다음 손실 증가가 없을 때 제한된 금액만 베팅한다. 사람의 시간 초과 기본값은 0원으로 유지한다.

미래 등급, 타인의 비공개 선택지, 실제 다음 난수는 판단에 사용하지 않는다. 모의 실행은 보수적인 고정 난수 조건이며 모든 확률적 경로를 완전히 탐색하지 않는다. 벽 설치는 근사 평가이고 장기 독점 계획·난이도별 성향·학습 모델은 구현 범위가 아니다.

## 검증

- 최신 변경 검증: 마블 테스트 233개 통과. 전용 전략 테스트 15개 포함.
- 이전 검증 기록: 2·3·4인, 증강 사용/미사용 각각 15시드: 총 90경기 모두 종료. 안전한 정수·비음수 잔액, 파산자 소유권, 불법 행동을 검사했다.
- 이전 화면 검증 기록: 공개 HTTPS 페이지에서 390px·1440px, 사람 1명과 봇 2~3명의 실제 연습 흐름을 각각 최소 6턴 진행했다. 페이지 오류·행동 오류·가로 넘침이 없었다.
- 원시 결과: [전략 봇 검증 JSON](augment-marble-bot-verification.json).
- 네트워크 검사는 무작위 초기 카드가 블라디미르인 경우 투척 전 대상을 선택하도록 보완했다.

이 결과는 이전 정책보다 사람 상대 승률이 높다는 증거가 아니다. 전략 간 대전과 실제 사용자 피드백으로 난이도를 조정할 수 있다.

## 로컬 실행 구성

- 게임 DB와 호스트의 기존 PostgreSQL 충돌을 피하기 위해 `docker-compose.local.yml`이 게임 DB만 `127.0.0.1:55432`에 노출한다.
- `.env`에 게임 DB 전용 계정을 설정했다. 기존 DB 계정 비밀번호는 변경하지 않았다. 비밀번호와 연결 문자열은 이 문서에 기록하지 않는다.
- DB·웹·게임 서버: `docker compose -f docker-compose.yml -f docker-compose.local.yml up -d dodo-postgres dynamodb-local activity-server activity-client`
- Discord 봇: `discordvenv/bin/python -m bot.main`. 공개 접속을 쓰려면 실행 환경의 `ACTIVITY_PUBLIC_URL`을 현재 HTTPS 주소로 지정한다.
- 공개 HTTPS 도메인으로 Discord 로그인하려면 해당 앱 개발자 포털의 OAuth2 Redirects에 `<현재 HTTPS 주소>/augment-marble`이 등록되어야 한다. 봇 토큰으로 이 설정을 변경하는 API는 Discord가 거부한다.
- 임시 터널 주소는 터널을 종료하거나 다시 만들면 달라질 수 있다.

- 근로장려금은 현금 500만원 미만에서만 자금 보충에 사용한다. 직전 자기 차례에 주사위를 던지지 않았다면 근로장려금·귀환석으로 연속 대기하지 않고 이동을 선택한다. 매입으로 즉시 독점 승리가 가능한 땅의 이동 가치를 우선한다.
